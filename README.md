# Защита маржи — Telegram-бот для Wildberries

Бот периодически читает товары и цены через API Wildberries, рассчитывает маржу по заданным вами расходам и присылает сводку, когда товар переходит ниже настроенного порога. Цены, скидки, карточки и остатки бот не изменяет.

## Что умеет текущая версия

- подключать токен WB и хранить его в SQLite только в зашифрованном виде;
- загружать товары и цены, задавать себестоимость и порог маржи;
- задавать расходы командой `/fees` (комиссия, логистика, налог, хранение и реклама);
- автоматически проверять маржу через настраиваемый интервал (по умолчанию 45 минут, допустимо 30–60);
- присылать сводное уведомление при переходе из нормального состояния ниже порога.

Остатки читаются клиентом, но оповещения о минимальном остатке пока не реализованы. Уведомления о приближении автоакций также не входят в текущую версию. При первом наблюдении товара ниже порога бот сохраняет исходное состояние; уведомление появится при последующем переходе через порог.

## Требования

- Python 3.11 или новее;
- токен Telegram-бота от BotFather;
- токен API Wildberries с правами только на чтение для нужных разделов.

Не выдавайте токену WB права на изменение цен, скидок, карточек или остатков. Клиент бота ограничивает запросы списком методов чтения. Команда `/connect` принимает токен в сообщении Telegram, затем бот пытается удалить это сообщение; если удалить его не удаётся, токен не сохраняется. Учитывайте, что сообщение до удаления обрабатывается Telegram.

## Запуск на компьютере

Выполняйте команды из корня проекта.

1. Создайте локальный файл настроек:

   ```sh
   cp .env.example .env
   ```

   В Windows скопируйте `.env.example` в `.env` средствами Проводника или командой `copy .env.example .env`.

2. В `.env` укажите `TELEGRAM_BOT_TOKEN`. Создайте ключ шифрования командой:

   ```sh
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```

   Вставьте результат в `TOKEN_ENCRYPTION_KEY`. Не меняйте и не теряйте этот ключ после подключения WB: без него сохранённые токены нельзя расшифровать. Храните ключ отдельно и безопасно вместе с резервной копией базы.

3. Создайте окружение, установите проект и запустите тесты:

   ```sh
   python -m venv .venv
   ```

   macOS/Linux:

   ```sh
   source .venv/bin/activate
   ```

   Windows:

   ```bat
   .venv\Scripts\activate
   ```

   Затем для любой системы:

   ```sh
   python -m pip install -e ".[dev]"
   pytest
   ```

4. Запустите бота:

   ```sh
   python -m margin_guard
   ```

   При старте создаётся `data/margin_guard.sqlite3`. Оставьте процесс запущенным, чтобы планировщик выполнял проверки.

## Команды бота

- `/start` — справка;
- `/connect` — подключение токена WB;
- `/products` — список товаров;
- `/cost` — задать себестоимость;
- `/fees` — настроить расходы;
- `/threshold` — задать порог маржи;
- `/status` — состояние мониторинга;
- `/pause` и `/resume` — приостановить или возобновить проверки;
- `/delete_me` — удалить данные пользователя.

Для значений расходов используйте фактические данные вашего кабинета и налогового режима. Бот не подставляет выдуманные комиссии. Если обязательных расходов для расчёта не хватает, маржа не рассчитывается.

## Запуск через Docker

Установите Docker, подготовьте `.env` по инструкции выше, затем из корня проекта выполните:

```sh
docker build -t margin-guard-bot .
docker run --rm --env-file .env -v "$PWD/data:/app/data" margin-guard-bot
```

Для Windows в Docker Desktop укажите абсолютный путь к папке `data` в синтаксисе volume, который поддерживает ваша оболочка. `.env` остаётся на хосте, SQLite-файл сохраняется в подключённой папке `data`. Контейнер запускает приложение от отдельного непривилегированного пользователя.

## Защита данных

- Не отправляйте `.env`, базу данных или ключ шифрования в Git и чаты.
- В репозитории находится только `.env.example` с фиктивными значениями; `.env`, локальная база и Python-окружения игнорируются Git.
- Логи приложения содержат только время, уровень и безопасные сообщения о запуске/остановке мониторинга. Подробные логи библиотек Telegram, HTTP и планировщика ограничены.
- Токен WB зашифрован Fernet в базе. Резервная копия базы без соответствующего ключа не позволит восстановить подключение.
- Используйте ограниченные права токена WB и отзывайте его в кабинете, если он больше не нужен.
